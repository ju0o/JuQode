## pty 를 넣지 않은 이유 — 그리고 넣지 않고도 되는 이유

`19` §C6 REC-010 은 "프로젝트당 pty 하나" 를 말하고, 같은 절이 **"Real T1 must validate: pty
libraries per runtime; Windows ConPTY"** 라고 적어 둔다. Canon 스스로 미검증으로 표시한 항목이다.

거기에 이 저장소의 자기 규칙이 겹친다: `tests/unit.test.js` 의 능력 격리 검사가 `node-pty` 를
**어디에도 없어야 하는 것** 목록에 넣어 두었다. 네이티브 모듈은 Electron 버전마다 재빌드가
필요하고(그래서 DB 도 `node:sqlite` 를 골랐다 — CF-5), 대상 OS 인 Windows 는 이 런에서
DEFERRED_VALIDATION 이다. 검증할 수 없는 OS 에서 네이티브 모듈을 새로 들이는 것은
**검증된 진척이 아니다.**

그런데 **Quick Command 는 pty 가 필요 없다.** REC-010 자신이 그렇게 적어 두었다 —
"Long-running Quick Commands run in **their own** child processes (not the drawer pty)".
그래서 이 배치는 pty 없이 갈 수 있는 데까지 전부 간다:

- 서랍(열기/닫기 · 상시 배너 · 화면 위에 뜨기 · 닫아도 아래 화면 보존)
- Quick Command 자연어 칸과 카드 전부(인식됨 · 미인식 · 모호함 · 사용 불가 · 실행 중 · 완료 ·
  실패 · 멈춤 · 계속 실행 중 · 할 수 있는 것 보기)
- 실행기(자기 자식 프로세스, 셸 없음)

**남은 것은 사용자가 직접 명령을 치는 셸 줄뿐이다.** 그건 pty 결정이 필요하고, DEFERRED_VALIDATION 에 있다.

## 셸이 없다는 것이 스폰까지 간다

`availability()` 가 문자열이 아니라 **argv** 를 낸다. 화면에 보이는 명령과 실제로 실행되는 인자
벡터가 같은 닫힌 데이터에서 나오고, 한쪽을 파싱해 다른 쪽을 만드는 코드가 없다. `spawn(program,
args)` 이고 `shell` 은 쓰지 않는다.

테스트가 그걸 실제로 잰다: `echo` 에 `x && touch CANARY` · `; rm -rf /` · `$(id)` · `` `id` `` 을
인자로 넘기고, **CANARY 가 생기지 않고 `$(id)` 가 확장되지 않는 것**을 확인한다. 그리고 어떤
규칙의 argv 도 셸(`sh` · `bash` · `cmd` · `powershell` …)을 program 으로 두지 않고 `-c` 를 넘기지
않는다는 것을 규칙표 전체에 대해 확인한다.

## 설명하고 · 확인하고 · 실행한다

`19` §C4 의 "항상 설명 후 확인" 을 **왕복 두 번**으로 강제했다. `juqode:qc-route` 는 인식하고
설명하고 아무것도 실행하지 않는다. `juqode:qc-run` 만 스폰한다. 타이핑으로 실행되는 경로가
구조적으로 없다 — 규율이 아니라 구조다.

가용성은 카드가 아니라 **실행 시점에 다시** 확인한다. 설명과 확인 사이에 프로젝트가 바뀔 수
있고, 카드는 스냅샷이다.

## 배너

`19` §S · Q-03 의 한 줄 — `여기서 치는 명령은 내 컴퓨터에서 내 권한으로 바로 실행돼요.` — 은
모든 상태에서 그려지고 닫히지 않는다. e2e 가 문자열을 **정확히** 비교한다. 이 줄이 사라지면
제품이 격리하지 않는다는 사실을 숨기는 것이다.

## 미인식은 오류가 아니다

`15` 가 중립으로 지정하고 `19` §C4 가 이유를 적어 둔다: 제품은 위험을 **감지한다고 말하지
않는다.** 감지한다고 하면 걸리지 않은 것은 안전하다고 가르치는 셈이다(q02 §5.7). e2e 가 카드에
`위험`·`감지`·`차단` 이 **없는지** 확인하고, 붉은색이 0개인지 확인한다.

## 가림은 줄이는 것이지 막는 것이 아니다

토큰 모양 텍스트를 표시 계층에서만 가린다. 코드가 "측정되지 않았다" 고 적어 두고,
**테스트가 그 인정 자체를 고정한다** — `hunter2` 는 가려지지 않는다는 것을 단언한다. 이게
없으면 다음 사람이 이걸 격리 경계로 착각한다.
