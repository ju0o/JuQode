## HIGH-1 · 제품이 있는 길을 없다고 말하고 있었다

`15` SC-02 는 두 카드에 **복구 버튼**을 요구한다:

- 기준 확립 불가 — **세 개의 복구 버튼**: `▸ 프로젝트 설명 읽기` · `▸ Quick Command 쓰기` ·
  `▸ 터미널로 직접 확인`
- Claude Code 사용 불가 — **네 개**: 위 셋 + `▸ 해결한 뒤 다시 보내기`

앱은 그 자리에 문장 하나를 그리고 있었다:

> 여기서 이어서 할 수 있는 것은 아직 만드는 중이에요.

그 문장이 쓰인 것은 WBS-04 · 22 · 25 가 아직 없을 때다. **셋 다 있다.** 프로젝트 설명(Brief)은
같은 화면에 있고, Quick Command 는 서랍에 있고, 터미널 서랍은 열린다. 제품이 사용자에게
**존재하는 길을 없다고** 말하고 있었다 — 숨기지 않는다는 원칙의 정반대다.

이제 셋(넷)이 진짜 버튼이고, 목적지가 서로 다르다:

| 버튼 | 어디로 |
|---|---|
| ▸ 프로젝트 설명 읽기 | 같은 화면의 Brief 를 펼친다 (WBS-05) |
| ▸ Quick Command 쓰기 | 서랍을 열되 **사용자가 이미 친 문장을 싣고** 간다 (D-134) |
| ▸ 터미널로 직접 확인 | 서랍을 그냥 연다 |
| ▸ 해결한 뒤 다시 보내기 | 같은 요청을 다시 보낸다 (사용 불가 카드만) |

`16` §2.1 의 초록 ▸ 는 복구다. 넷 다 사용자가 고르지 않은 상태에서 빠져나가는 길이므로 복구가
맞고, 이동(navigation)이 아니다.

### 그리고 이 상태에 그려진 증거가 하나도 없었다

`12` §16 의 간판 상태(**사용 불가 ≠ 실패**)인데 e2e 가 한 번도 거치지 않았다. 픽스처 CLI 가
표식 파일 하나로 **로그아웃 상태**를 흉내 내게 해서, 실제 탐지 코드 경로로 카드를 띄운다.
`detect()` 는 캐시가 없어서 preflight 마다 다시 돈다.

재는 것: 카드가 뜨고 · `지금 안 됨 · 실패 아님` 칩이 있고 · 이유를 말하고 · **빨강이 0** 이고 ·
**버튼이 정확히 그 넷** 이고 · 적은 텍스트가 칸에 그대로 남고(UF-RULE-NOQUEUE) ·
`▸ Quick Command 쓰기` 가 **문장을 싣고** 서랍을 연다.

돌연변이로 확인: 복구 버튼 줄을 지우면 `the four recovery paths are not four buttons: ["▸ 해결한 뒤 다시 보내기"]`.

## HIGH-2 · 죽은 문구를 잡는 검사가 없었다

`copy.js` 머리말이 이렇게 적혀 있다: *Keys not yet needed by a built screen are deliberately
absent.* 아무도 확인하지 않았고, 스물한 개가 그 규칙 밖에 있었다.

문구는 코드보다 더 조용히 썩는다. 아무도 부르지 않는 키는 컴파일 오류도 테스트 실패도 내지
않고, 그 사이에 세상이 바뀌어 **문장이 거짓이 된다.** 위의 둘이 정확히 그것이다.

검사를 넣었다: `copy.js` 의 모든 잎 키가 렌더러 어딘가에서 실제로 참조되는가.

두 가지 함정을 피한다:

1. **동적 접근.** `C.orient[…]` · `C.gap.signal[…]` 처럼 계산된 인덱스로 읽는 부모는 잎 전부를
   쓰는 것으로 친다. 하나씩 나열하면 갱신을 잊을 목록이 하나 더 생긴다.
2. **주석.** 처음엔 주석을 포함해 검색했더니 `history.more` 가 **쓰이는 것처럼 보였다** — 다른
   파일의 산문이 그 단어를 담고 있었다. 주석에 이름이 나오는 것은 화면이 그리는 것이 아니다.

### PENDING 은 면제가 아니라 할 일 목록이다

아직 그릴 수 없는 일곱은 목록에 이름과 **이유**를 적어 두었다(SC-01 의 마지막 작업 요약 ·
SC-03 의 남은 변경 확인 불가 · 상대 시각 · TD-01 사용 불가 3종 · DV-11 의 mock · 출력 전체 보기).
그리고 **PENDING 자체가 낡는 것도 검사한다** — 이미 그려진 것을 계속 면제하고 있으면 실패한다.
면제 목록이 영구가 되는 경로를 막는 것은 그 한 줄이다.
