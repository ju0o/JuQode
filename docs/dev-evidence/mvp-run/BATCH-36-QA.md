## 2. 제품 결함 셋

1. **Work 가 도는 중에도 `아직 요청한 작업이 없어요` 라고 말했다.** 근거가 없는 문장이다.
   SC-02 에 현재 Work 표면이 아예 없었고, 도는 Work 는 기록 행의 `진행 중` 칩으로만 보였다.
2. **실패한 Work 에 `변경 읽기` 가 조건 없이 붙어 있었다.** 바뀐 파일이 0 이면 빈 리더를 여는
   버튼이다. `15` 는 `changesApplied > 0` 일 때만이라고 쓴다 — 빠진 것은 문장이 아니라 **조건**
   이었다 (`바뀐 파일이 없어요` 는 이미 그려지고 있었다).
3. **가드 카드에 `15` 가 이름 붙인 네 동작 중 하나만 있었다.** 그중 `기다리기` 를 앞선 배치가
   "누르지 않으면 일어나는 일이니 컨트롤이 아니다" 로 접었는데, **그 판단이 틀렸다.** 닫을
   길이 없으면 그 알림은 사용자가 아직 들고 있는 요청 위에 그대로 앉아 있는다. 승인
   프로토타입의 핸들러도 `S.guard=false` — 카드를 닫는 것이다.

## 3. 게이트 ① · ② — 중복이 아니었다

`18` 이 `presence.title` 을 **접었다**(같은 네 글자 · §0.8). 나머지 셋은 중복으로 분류돼
있었지만 **아니었다** — 각각 다른 표면의 이름이고, 아무 화면도 그리지 않고 있었을 뿐이다:
`work.observed`(No-Step liveness 분기) · `work.open`(SC-02 현재 Work 카드) ·
`qc.kicker`(QC 카드 자신의 머리줄).

`15` 부록이 컨트롤 일곱 개의 자리를 정해 주어 다섯을 구현했다. **PENDING 문구 목록 12 → 3.**

## 4. 내 검사에서 나온 것 둘

**① 크래시가 남긴 빨간 단언.** `visual.mjs` 가 Brief 의 여섯 답을 **도착 직후**에 읽고
있었다. D-138 은 해석이 끝나면 접힘이 기본이므로 그 자리에서 0 이다. 기본 상태를 먼저 재고,
여섯 답은 사용자가 `펼치기` 를 누른 자리에서 잰다.

> 검사도 개정을 따라간다. `17` 의 옛 규칙("여러 카드 · 여러 크기")을 단언하던 블록은
> **외부 리뷰가 혼란스럽다고 한 바로 그 배치를 통과시키고 있었다.** 검사는 카드의 벽을
> 금지하는 것만큼 쉽게 강제한다.

**② 시각 QA 가 잡았다.** 좁아진 레일의 머리줄이 자기 버튼을 라벨보다 좁게 눌러
`다시 읽\n기` · `펼치\n기` 로 낱말이 가운데서 끊겼다 (1024 에서 더 심했다).
**단언은 전부 초록이었다.** `flex-wrap` + 버튼 `flex: 0 0 auto` 로 고치고, Range 의 줄 수를
세는 검사(`railHeadBroken`)를 남겼다.

## 5. 후속 — PM 폐기 판정 (`bee695c`)

PM 이 Gate ② 의 남은 둘을 **폐기**로 판정했다: `work.requested`(문구 키가 있다는 이유로
라벨을 붙이지 않는다 — 요청문이 스스로를 이름한다) · `qc.terminal`(목적지가 이미 들어와
있는 표면인 컨트롤은 동작이 아니다).

**구현은 이미 둘 다 만든 적이 없다.** 고칠 코드가 없었고, 문제는 **부재가 측정되지 않았다는
것**이었다 — 다음 배치가 "백로그를 끝낸다" 며 둘을 만들어 버리는 것을 막을 것이 없었다.

다섯 검사를 넣었고 **전부 쌍이다.** 한쪽만 걸면 반대로 깨지기 때문이다:

| 지키는 것 | 함께 지키는 것 |
|---|---|
| SC-03 에 요청문이 **있다** | 그 위에 `요청한 말` 라벨이 **없다** |
| Quick Command 가 **TD-01 안에** 있다 (D-134) | QC 카드에 `터미널` 링크가 **없다** |

라벨 검사만 있으면 머리줄째 지워도 통과하고, 링크 금지만 있으면 QC 를 서랍 밖으로 옮겨도
통과한다. 라벨은 **문구 키가 아니라 렌더된 글자**로 본다 — 키를 지운 뒤에도 그대로 선다.

**Test Adversary — 일곱 개 위반을 주입해 전부 빨개지는 것을 확인:** 요청문 삭제 · 라벨 부활 ·
QC 를 서랍 밖으로 · 자기참조 터미널 링크 · 레일 낱말 끊김 · Brief 가 주어가 됨 · 너비가 보드
순위를 바꿈.

PENDING 목록에서는 **아직 빼지 않았다.** `18` · `15` 가 폐기를 기록한 뒤다 — 이 프로젝트는
문구를 `18` 에서 먼저 고치고 `copy.js` 에서는 고치지 않는다.
