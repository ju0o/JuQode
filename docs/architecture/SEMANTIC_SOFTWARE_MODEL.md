## 1. 자리는 개체가 아니다 — 그러나 저장은 동일성을 요구한다

Canon: **테두리가 없다 · 셀 수 없다 · 떼어낼 수 없다. 재료의 성질이다.**
그러나 Problem 은 자리에 매여야 하고, 이름 정정은 재스캔에도 살아남아야 한다.

**해소 — 안이 아니라 밖에서 개체가 아니다.**

| | |
|---|---|
| **내부** | `place_id` 는 **안정된 식별자**다. 한 번 생기면 바뀌지 않는다 |
| **사용자** | 만들 수도 지울 수도 옮길 수도 없고 **목록으로 열거되지 않는다.** 이름은 집혔을 때만 온다 |
| **겹침** | 자리 ↔ 소스는 **N:N**. 분할이 아니다 |

---

## 2. 동일성 구조

```
SemanticPlace           안정된 내부 place_id · current_revision → · confidence
SemanticPlaceRevision   place_id · mapping_fingerprint · source_mappings · model_version
PlaceNaming             place_id · name · origin      ← 지문이 아니라 '자리'에 붙는다
```

> ## **매핑 지문은 재식별 신호다. 동일성이 아니다.**

| | |
|---|---|
| 재스캔 | 지문을 비교해 *"같은 자리인가"* 를 **확신도와 함께** 판정한다 |
| 확신이 높으면 | 같은 `place_id` 에 새 revision → **이름 정정 · Problem · Evidence 가 살아남는다** |
| 확신이 낮으면 | 새 자리로 본다. **옛 자리를 지우지 않는다** — 사람이 이을 수 있다 |
| 목표 | **평범한 리팩터를 정정이 견뎌야 한다** |

---

## 3. 자리는 어떻게 나오는가

```
진입점 씨앗  +  의존 / 구조 로컬 사실  +  AI 의미 해석  +  사람 정정
                                              │
                                 확신 낮음 → 『모르는 곳』
```

| 규칙 | |
|---|---|
| 파일 빈도는 자리를 만들지 못한다 | 질량의 하한으로만 |
| 폴더는 자리가 아니다 | 폴더는 분할이고 자리는 겹친다 |
| **한 화면에 또렷이 그리는 자리는 5~7개** | **렌더링 예산이지 모델의 상한이 아니다** |
| 뜻이 없는 곳은 `모르는 곳` | 발명하지 않는다 |

> `confidence`(뜻을 아는가)와 **"지금 그리는가"** 는 **서로 다른 축이다.**
> 예산 밖을 `UNKNOWN` 으로 적으면 **아는 것을 모른다고 거짓말하는 것**이다.

## 4. 이름

**JuQode 가 제안한다 → 사용자가 고칠 수 있다 → 정정은 안정된 자리 동일성에 붙어 남는다.**

우선순위 `USER_CORRECTION > AI_INFERENCE > LOCAL_FACT`.
겹친 자리는 **두 이름을 다 갖는다.** 강제로 하나를 고르지 않는다.

---

## 5. Realm 독립

자리 · 질량 · 상태 · 증거는 **Realm 에 묶이지 않는다.**
v0.1 은 Field/Grain 하나만 쓰지만 모델에 Realm 어휘가 들어가지 않는다.
