## 1. 되돌리기 = 안전감 = v0.1 의 핵심 가치

**Return Safety 세 조건**

1. 사라지는 것과 **남는 것**을 함께 예고한다
2. **되돌리기 자체가 되돌려진다**
3. 버린 상태는 **보관된다** — *"약속한 숫자와 보관한 숫자가 달라서는 안 된다"*

---

## 2. 트리 둘 안전 모델

**스냅샷은 트리 하나가 아니라 둘이다.** 인덱스는 워킹트리와 별개의 상태다.

```
INDEX TREE   사용자의 스테이징 그대로   (인덱스를 읽기만 한다)
WORK TREE    워킹트리 그대로 (미추적 포함)
```

```
refs/juqode/safety/<exec>/work     Qode 직전 워킹트리
refs/juqode/safety/<exec>/index    Qode 직전 사용자 스테이징
refs/juqode/discarded/*            되돌리기로 버려진 상태 — 보관된다
refs/juqode/equilibrium/*          확인된 평형 = Software Time 의 점
```

**복원 순서 — 사용자 인덱스를 `HEAD` 로 리셋하지 않는다.**

```
① 스냅샷 이후 생긴 파일만 정확히 지운다
② 워킹트리를 WORK TREE 로 되돌린다      (별도 인덱스로 checkout-index)
③ 사용자 인덱스를 INDEX TREE 로 되돌린다  ← HEAD 가 아니다
```

## 3. 보존되는 것 — 실측 확인

| | |
|---|---|
| 더러운 상태 · 스테이징 · **부분 스테이징** | ✔ |
| 미추적 파일 | ✔ |
| **HEAD** | ✔ 불변 |
| 이름 변경 staging · 삭제 · 심링크 · 중첩 저장소 | ✔ |
| **되돌리기의 되돌리기** | ✔ |
| **사용자에게 보이는 Git 이력** | **더럽히지 않는다** — `refs/juqode/*` 는 `git log` 에 안 뜬다 |

---

## 4. 자동 Qode 를 지원하지 않는 상태

```
병합 충돌 / unmerged 인덱스
무시된 파일 쓰기
중첩 저장소 / 서브모듈 쓰기
그 밖의 특수 인덱스 상태
되돌릴 수 있음을 증명할 수 없는 모든 상태
```

> ## **안전 프로브가 되돌릴 수 있음을 증명하지 못하면 Qode 를 실행하지 않는다.**
>
> 이유는 **사람 말로** 말한다. `commit` · `index` · `stash` 같은 Git 어휘를 쓰지 않는다.

---

## 5. 무시된 파일

| | |
|---|---|
| **에이전트 자동 쓰기** | **DENY** |
| **되돌리기** | **약속하지 않는다** |
| 왜 | `.gitignore` 대상은 스냅샷 밖이다. **되돌린다고 말하면 거짓말이다** |

---

## 6. 더러운 저장소에서는 멈춰 세우지 않는다

정확한 안전 스냅샷이 성립하면 **확인 모달로 사용자를 끊지 않는다.**
되돌릴 수 있음이 증명되었으므로 멈춰 세울 이유가 없다.

선택적 안심 문구: **"작업 중이던 내용도 함께 보관했어요."**

---

## 7. 어휘 — 사용자가 보는 것은 셋뿐

```
그때 보기     ·     지금과 비교     ·     여기로 돌아가기
```

**노출하지 않는 말:** `commit` `branch` `HEAD` `checkout` `reset` `revert` `rebase` `hash`
및 그 한국어 대응.

---

## 8. 미결

- **대형 저장소의 스냅샷 시간** — 측정하지 않았다 (**D1 / E1**)
- **병합 충돌 상태에서의 사람 말 문구** — 정책은 정해졌으나 문구가 없다 (**E1 / QA**)
