## 1. 되돌리기 = 안전감 = v0.1 의 핵심 가치

`04` §8 Anti-Goals: *"Git 은 어려우니 v0.1 에서 빼자"* 는 금지되어 있다.
되돌리기가 안전하지 않으면 v0.1 의 핵심 가치가 없다.

**Return Safety 세 조건 (D-045)**

1. 사라지는 것과 **남는 것**을 함께 예고한다
2. **되돌리기 자체가 되돌려진다**
3. 버린 상태는 **보관된다** — *"약속한 숫자와 보관한 숫자가 달라서는 안 된다"*

## 2. 다섯 방법을 실제로 비교했다

| 방법 | 미추적 파일 담김 | 사용자 상태 불변 | 이력 오염 | 판정 |
|---|---|---|---|---|
| 커밋 | ✅ | ❌ HEAD 가 움직인다 | ❌ 사용자 이력에 낀다 | **기각** |
| `stash create` | ❌ **실측 실패** | ✅ | ✅ | **기각** |
| 패치 파일 | ✅ | ✅ | ✅ | 보조로만 |
| worktree | 부분 | ✅ | ✅ | **v0.1 연기** |
| **스냅샷 객체 + 자체 ref** | ✅ | ✅ **실측 확인** | ✅ | **제안** |

> `stash` 가 기각된 이유가 중요하다 — **초보자가 만드는 새 파일이 정확히 미추적 파일이다.**
> 그것을 못 담는 안전장치는 안전장치가 아니다.

---

## 3. 제안 — 스냅샷 커밋 객체 + `refs/juqode/*`

```
refs/juqode/safety/<execution_id>      Qode 직전. 되돌아갈 곳
refs/juqode/discarded/<rollback_id>    되돌리기로 버려진 상태. 보관된다
refs/juqode/equilibrium/<time_id>      확인된 평형. Software Time 의 점
```

별도 인덱스로 트리를 쓰고 커밋 객체를 만든 뒤 자체 ref 로 붙잡는다.
**HEAD · 인덱스 · 워킹트리를 하나도 건드리지 않는다** — 실측 확인.

| 성질 | 어느 약속을 참으로 만드는가 |
|---|---|
| 사용자 상태 불변 · `git log` 에 안 뜬다 | 하던 일이 끊기지 않는다 |
| ref 가 GC 로부터 지킨다 | **"보관됨 · 없어지지 않았습니다"** (조건 3) |
| 되돌리기 전에 먼저 보관한다 | **되돌리기의 되돌리기** (조건 2) |
| 두 트리를 비교해 목록을 만든다 | 사라지는 것/남는 것이 **계산된 사실**이 된다 (조건 1) |
| 약속 목록 = 보관 객체의 실제 내용 | 같은 객체에서 나오므로 **구조적으로 일치한다** |

## 4. 여덟 질문에 대한 답 (전부 실측 근거 있음)

| 질문 | 답 |
|---|---|
| Qode 전에 저장소가 더럽다면 | **그대로 진행한다.** 스냅샷이 전부 담는다 |
| 추적 안 된 파일은 | **담긴다** |
| 사용자 변경과 JuQode 변경 구분 | 에이전트 시작 **직전** 스냅샷. 그 이후 차이만 JuQode 의 것 |
| 되돌리기 구현 | 스냅샷 이후 **새로 생긴 것을 정확히 지우고** 스냅샷으로 되돌린다 |
| 되돌려도 남는 것 | `.gitignore` 대상(`node_modules` 등)은 **건드리지 않는다** |
| 되돌리기의 되돌리기 | 되돌리기 직전 상태를 먼저 보관한다 |
| Git 저장소가 없다면 | **프로젝트 밖의 그림자 저장소.** 사용자 폴더에 `.git` 이 생기지 않는다 |

> **찾은 함정:** 나이브한 복원은 **거짓이다** — 스냅샷 이후 생긴 파일이 그대로 남는다.
> "그때 그대로"를 참으로 만들려면 추가된 파일을 **정확히 열거해서 지워야** 한다.

---

## 5. 어휘 — 위의 모든 문자열은 내부다

사용자가 보는 것은 셋뿐이다.

```
그때 보기     ·     지금과 비교     ·     여기로 돌아가기
```

**노출하지 않는 말:** `commit` `branch` `HEAD` `checkout` `reset` `revert` `rebase` `hash`
및 그 한국어 대응(커밋 · 브랜치 · 병합).

---

## 6. 정직하게 남기는 한계

1. `.gitignore` 된 것은 스냅샷에 없다 → **되돌려도 안 돌아온다.**
   대개 옳지만(빌드 산출물), 사용자가 `.env` 를 무시했다면 그것도 안 돌아온다. **화면이 이 사실을 말해야 한다.**
2. **매우 큰 저장소의 스냅샷 시간은 측정하지 않았다.** 실험은 작은 저장소였다
