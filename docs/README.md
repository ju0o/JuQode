# JuQode — Public Technical Specifications

> **이 디렉터리는 아직 비어 있다. 의도된 것이다.**

---

## 왜 비어 있는가

JuQode는 현재 **Product 정의 단계(Phase 0 완료)** 에 있다.

Product Strategy · PRD · UX · Roadmap은 **JuQode-Private**에 있으며,
이 저장소에는 **공개 가능한 기술 명세만** 둔다.

공개 대상이 되기 위한 판단 기준:

1. 제품 전략 / UX 판단 / 사업 관련 내용이 드러나지 않는가
2. 외부에서 참조하거나 구현할 가치가 있는가
3. 비공개 정보가 섞이지 않았는가

---

## 향후 공개 후보

아래는 **후보이며 확정된 공개 계획이 아니다.**

| 후보 | 내용 |
|---|---|
| Context Block Format Spec | Context를 파일로 내보내고 가져오는 형식 |
| Agent Event Schema | Agent 작업 이벤트의 구조화된 표현 |
| Evidence Schema | Test / Build / Screenshot / Git 검증 결과의 표현 |

**Context Block Format을 사람이 읽을 수 있는 형식으로 유지하는 것**은
JuQode의 결정 사항이다 — 사용자가 자기 Context를 언제든 밖으로 가져갈 수 있어야 한다.
그 형식이 확정되면 이 저장소에 공개된다.
